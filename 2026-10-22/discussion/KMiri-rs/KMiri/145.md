## Body

* https://github.com/KMiri-rs/KMiri/issues/144


**1) 板级内存区定义（layout.ld）**
见 [`boards/qemu_rv64_virt/layout.ld#L13-L18`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/qemu_rv64_virt/layout.ld#L13-L18) 和 [`boards/qemu_rv64_virt/layout.ld#L26-L30`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/qemu_rv64_virt/layout.ld#L26-L30)

- `rom`: `0x8000_0000 .. 0x8010_0000` (1 MiB)
- `prog`: `0x8010_0000 .. 0x8020_0000` (1 MiB)
- `ram`: `0x8020_0000 .. 0x8040_0000` (2 MiB)
- `_sflash = ORIGIN(rom) = 0x8000_0000`
- `_eflash = ORIGIN(prog) + LENGTH(prog) = 0x8020_0000`
- `_ssram = ORIGIN(ram) = 0x8020_0000`
- `_esram = ORIGIN(ram) + LENGTH(ram) = 0x8040_0000`

**2) 通用内核链接脚本里这些符号的定义位置**
见：

- `_stext` 在 [`boards/build_scripts/tock_kernel_layout.ld#L65`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/build_scripts/tock_kernel_layout.ld#L65)
- `_etext` 在 [`boards/build_scripts/tock_kernel_layout.ld#L224`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/build_scripts/tock_kernel_layout.ld#L224)
- `_sapps` / `_eapps` 在 [`boards/build_scripts/tock_kernel_layout.ld#L308`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/build_scripts/tock_kernel_layout.ld#L308) / [`boards/build_scripts/tock_kernel_layout.ld#L324`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/build_scripts/tock_kernel_layout.ld#L324)
- `_sappmem` / `_eappmem` 在 [`boards/build_scripts/tock_kernel_layout.ld#L363`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/build_scripts/tock_kernel_layout.ld#L363) / [`boards/build_scripts/tock_kernel_layout.ld#L366`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/build_scripts/tock_kernel_layout.ld#L366)

**3) 这些符号在板代码中的声明与使用**
见 [`boards/qemu_rv64_virt/src/main.rs#L116-L150`](https://github.com/KMiri-rs/tock/blob/800bec574f107bb01b86b8898217d688c75ea181/boards/qemu_rv64_virt/src/main.rs#L116-L150)

- `extern "C"` 声明符号
- `load_processes()` 用 `_sapps.._eapps` 作为 app flash 区间，用 `_sappmem.._eappmem` 作为 app RAM 区间

**4) ELF 里实际符号地址（我本地构建产物实测）**

- `_stext    = 0x80000000`
- `_etext    = 0x8001b600`
- `_sflash   = 0x80000000`
- `_eflash   = 0x80200000`
- `_sapps    = 0x80100000`
- `_eapps    = 0x80200000`
- `_ssram    = 0x80200000`
- `_esram    = 0x80400000`
- `_sappmem  = 0x8021b680`
- `_eappmem  = 0x80400000`

**5) 放到内存布局中（按地址）**

- `0x80000000`: `_stext` / `_sflash`
- `0x8001b600`: `_etext`
- `0x80100000`: `_sapps`
- `0x80200000`: `_eapps` / `_eflash` / `_ssram`
- `0x8021b680`: `_sappmem`
- `0x80400000`: `_eappmem` / `_esram`
