## `make check` 完整调用链

### 第一层：Makefile

```makefile
BOARD := qemu_riscv64
BUILD_MODE := debug
OUT_DIR := out/qemu_riscv64.debug

gen:
    gn gen out/qemu_riscv64.debug --args='build_type="debug" board="qemu_riscv64"'

check: gen
    ninja -C out/qemu_riscv64.debug check_all
```

`make check` 先跑 `gn gen`（生成 ninja 文件），再跑 `ninja check_all`。

---

### 第二层：GN 文件如何生成 ninja

GN 从根目录开始读 `.gn` → `build/BUILDCONFIG.gn`（toolchain 默认值），然后递归解析所有 `BUILD.gn`：

```
BUILD.gn (顶层)
└── group("check_all")
    └── deps = ["//build/boards/qemu_riscv64:check_all"]

build/boards/qemu_riscv64/BUILD.gn
├── import("//build/default_targets.gni")      # 定义 check_all_on_virtual_board
├── import("//build/templates/board.gni")      # 定义 blueos_board 模板
└── blueos_board("qemu_riscv64")
    └── check_all = filter_exclude(
            check_all_on_virtual_board + clippy_all_on_virtual_board,
            ["//kernel/adapter*"]   # 排除 adapter
        )
```

`build/default_targets.gni` 展开后（排除 adapter 后）有效 deps：

| target                                   | 说明                       |
| ---------------------------------------- | -------------------------- |
| `//apps/shell:shell`                     | shell 应用                 |
| `//kernel/kernel:check_kernel`           | kernel 单元测试 + 集成测试 |
| `//kernel/loader:check_loader`           | loader 测试                |
| `//kernel/rsrt:check_rsrt`               | rsrt 测试                  |
| `//librs:check_librs`                    | libc 实现测试              |
| `//kernel/kernel:check_kernel_by_clippy` | clippy lint                |
| `//librs:check_librs_by_clippy`          | clippy lint                |
| ...其余 clippy 目标                      |                            |

---

### 第三层：以 `check_kernel` 为例的完整展开

```
kernel/kernel/BUILD.gn
└── group("check_kernel")
    ├── :run_unittest
    │   └── run_qemu_check("run_unittest")     # 模板在 build/toolchain/blueos.gni
    │       ├── deps: :unittest_runner
    │       │   └── gen_qemu_runner("unittest_runner")
    │       │       └── action: python build/scripts/gen_qemu_runner.py
    │       │           生成 3 个 shell 脚本 →
    │       └── action: python build/scripts/qemu_checker/qemu_checker.py
    │           -s <runner>.sh  -t <test_dir>  src/unittests.checker
    │
    └── :run_integration_test
        └── run_qemu_check("run_integration_test")
            ├── deps: :integration_test_runner
            │   └── gen_qemu_runner("integration_test_runner")
            │       └── action: python build/scripts/gen_qemu_runner.py
            └── action: python build/scripts/qemu_checker/qemu_checker.py
                -s <runner>.sh  -t <test_dir>  tests/integration.checker
```

---

### 第四层：最终生成的 bash 命令

**`gen_qemu_runner.py`** 为每个测试生成 3 个 shell 脚本（以 `unittest_runner` 为例，板子为 `qemu_riscv64`）：

**`unittest_runner-qemu.sh`**（qemu_checker 实际执行的）：
```bash
#!/bin/bash
exec qemu-system-riscv64 -accel tcg -semihosting-config enable=on \
     -M virt -bios none -smp 32 \
     -kernel <out>/bin/kernel_unittest \
     -nographic
```

**`unittest_runner-qemu-test.sh`**（带日志输出）：
```bash
#!/bin/bash
exec qemu-system-riscv64 -accel tcg -semihosting-config enable=on \
     -M virt -bios none -smp 32 \
     -kernel <out>/bin/kernel_unittest \
     -nographic \
     -serial file:<logfile> \
     -d int,cpu_reset,guest_errors,unimp -D <syslog>
```

**`unittest_runner-qemu-dbg.sh`**（带 GDB stub）：
```bash
#!/bin/bash
exec qemu-system-riscv64 -accel tcg -semihosting-config enable=on \
     -M virt -bios none -smp 32 \
     -kernel <out>/bin/kernel_unittest \
     -nographic -s -S
```

`-bios none -smp 32` 来自 `qemu_riscv64.gni` 的 `qemu_extra_args`，`-accel tcg -semihosting-config enable=on` 因为 `semihosting = true`。

---

### 第五层：qemu_checker.py 如何验证结果

`qemu_checker.py` 执行 `*-qemu.sh`，读取其 stdout，同时对照 `.checker` 文件中的指令（如 `src/unittests.checker`）逐行匹配：

```
// ASSERT-SUCC: <regex>   → 匹配到则判定成功，立即退出
// ASSERT-FAIL: <regex>   → 匹配到则判定失败，立即退出
// CHECK-SUCC: <regex>    → 记录成功行（不终止）
// CHECK-FAIL: <regex>    → 记录失败行（不终止）
// TOTAL-TIMEOUT: <秒>    → 总超时
// NEWLINE-TIMEOUT: <秒>  → 行间超时
```

---

### 总结：完整链路

```
make check
  └── gn gen → 读取所有 .gn/.gni 文件，生成 out/qemu_riscv64.debug/build.ninja
  └── ninja check_all
        └── 编译 kernel_unittest / kernel_integration_test (rustc)
        └── gen_qemu_runner.py → 生成 *-qemu.sh 脚本
        └── qemu_checker.py → 执行 *-qemu.sh（实为 qemu-system-riscv64 命令）
                           → 用 .checker 文件的正则规则验证 QEMU 输出
```
