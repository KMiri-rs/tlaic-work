## Body

> MinHeapNode 内部的 LinkType 是什么什么功能？尤其是泛型参数，以及 MinHeapNode 的 node_of、node_of_link、owner_ptr、link_ptr 这几个转化指针的方法，它们的基本逻辑是什么

## 📋 总体架构概览

### **MinHeapNode 的内存布局**

```rust
pub struct MinHeapNode<T, A: const Adapter<T>> {
    // ↑ 第一个字段是 link，这是关键设计决策
    link: LinkType<T, A>,          // ← 0 offset，不需要复杂嵌套适配器
    parent: Option<NonNull<MinHeapNode<T, A>>>,
}
```

---

## 🔍 LinkType 是什么？

### 定义
```rust
type LinkType<T, A> = ListHead<T, Nested<T, A, MinHeapNode<T, A>, Link<T, A>>>;
```

这是一个经过参数传递的**双链表节点类型**。让我们分解泛型参数：

| 泛型                                          | 含义                                               |
| --------------------------------------------- | -------------------------------------------------- |
| `T`                                           | 容器中的元素类型（实际存储的数据）                 |
| `Nested<T, A, MinHeapNode<T, A>, Link<T, A>>` | **嵌套适配器**，用于从 `LinkType` 定位到完整的 `T` |

### **Nested 适配器的计算逻辑**

```rust
// Nested<P, S, N, T> 的 offset = S::offset() + T::offset()
const impl<P, S: const Adapter<P>, N, T: const Adapter<N>> Adapter<P> 
    for Nested<P, S, N, T> 
{
    fn offset() -> usize {
        S::offset() + T::offset()  // ← 累加偏移量！
    }
}
```

应用到 `ListHead<T, Nested<...>>` 中：

```
Nested<T, A, MinHeapNode<T, A>, Link<T, A>>::offset()
= A::offset()         // T 内部 node 字段的偏移
+ Link::<T, A>::offset()   // MinHeapNode 内部 link 字段的偏移
```

这个值表示：**从 `T` 实例开头到 `LinkType` 字段开头的字节距离**

---

## 🎯 四个指针转换方法的逻辑

### 1️⃣ `node_of(this: &mut T) → NonNull<Self>`

**目的**：从完整对象 `T` 定位到嵌入的 `MinHeapNode`

```rust
fn node_of(this: &mut T) -> NonNull<Self> {
    NonNull::from(this)                                    // T 的地址
        .map_addr(|addr| addr.get().wrapping_add(A::offset()))  // 加上 T→MinHeapNode 的偏移
        .cast()                                            // 转换为 NonNull<MinHeapNode<T, A>>
}
```

**流程**：
```
T 地址 ──[+A::offset()]──> MinHeapNode 地址
示例：Entry (key+node) ──[+entry.node.offset]──> MinHeapNode
```

---

### 2️⃣ `node_of_link(link: NonNull<LinkType>) → NonNull<Self>`

**目的**：从双向链表的 link 字段反向定位到 MinHeapNode

```rust
fn node_of_link(link: NonNull<LinkType<T, A>>) -> NonNull<Self> {
    link.map_addr(|addr| {
        addr.get()
            .wrapping_sub(Link::<T, A>::offset())  // ← 减去 Link 的偏移
            .try_into()
            .unwrap()
    })
    .cast()
}
```

**流程**：
```
LinkType 地址 ──[−Link::offset]──> MinHeapNode 地址
              = ──[−nested_offset]──> MinHeapNode 地址
```

**为什么是 `wrapping_sub`？** 因为 `Nested::offset()` 可能比 `LinkType` 大很多，需要反向移动找到父结构体。

---

### 3️⃣ `owner_ptr(node: NonNull<Self>) → *mut T`

**目的**：从 `MinHeapNode` 恢复指向完整对象 `T` 的裸指针

```rust
fn owner_ptr(node: NonNull<Self>) -> *mut T {
    node.map_addr(|addr| addr.get().wrapping_sub(A::offset()).try_into().unwrap())
        .as_ptr()
        .cast()
}
```

**流程**：
```
MinHeapNode 地址 ──[−A::offset]──> T 地址
                = ──[−entry.node.offset]──> Entry 地址
```

---

### 4️⃣ `link_ptr(node: NonNull<Self>) → NonNull<LinkType<T, A>>`

**目的**：直接获取 `MinHeapNode` 内部的 `link` 字段指针

```rust
unsafe fn link_ptr(node: NonNull<Self>) -> NonNull<LinkType<T, A>> {
    NonNull::new_unchecked(core::ptr::addr_of_mut!((*node.as_ptr()).link))
}
```

**特点**：
- 使用 `addr_of_mut!` 宏，这是零成本的安全指针获取
- 不通过地址计算，直接在编译期确定 `link` 的相对位置

---

## 🔗 完整的数据流向图

```
┌─────────────────────────────────────────────────────┐
│                   T (如 Entry)                      │
│  key: usize                                         │
│  node: MinHeapNode<Entry, EntryAdapter>            │
│     ↑ 位于 offset N                                  │
│     ├─ link: LinkType                               │
│     │    ↑ 位于 offset N                             │
│     │    ├─ prev/next                               │
│     └─ parent                                       │
└─────────────────────────────────────────────────────┘

路径转换：
1. T → MinHeapNode : node_of(T)      [加 A::offset()]
2. LinkType → MinHeapNode : node_of_link  [减 Link::offset()]
3. MinHeapNode → T : owner_ptr           [减 A::offset()]
4. MinHeapNode → LinkType : link_ptr     [直接使用 addr_of_mut!]
```

---

## 💡 核心设计思想

### 为什么这样设计？

1. **避免 borrow checker 冲突**  
   - 原代码使用 `as_ref()/as_mut()` 创建临时引用，会占用借用，导致无法同时操作父节点
   - 新代码全部使用 `NonNull` 裸指针，直到最后才解引用

2. **保持 provenance（来源）**  
   - `map_addr` 保留了原始指针的所有权来源信息
   - 允许在运行时动态恢复 `&T` 引用

3. **最小化字段偏移依赖**  
   - `LinkType` 作为 `MinHeapNode` 的第一个字段（offset=0）
   - 避免了复杂的嵌套适配器计算
   - 注释说明了这一点：`"Put the link first so that we don't need to use the complex Nested adapter"`
