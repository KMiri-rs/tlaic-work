## Rust for Linux：kernel 单元测试与 doctest 在 Miri 上跑通

```bash
# kernel 单元测试
$ make -f makefile.local miri
  MIRI T  rust/kernel/lib.rs
running 6 tests
test bitmap::tests::bitmap_borrow ... ok
...
test result: ok. 6 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out

# doctest（352 个中 261 个通过，74%，另有 91 个 Miri 暂无法处理）
$ make -f makefile.local miri-doctest-fast
running 261 tests
...
test result: ok. 261 passed; 0 failed; 0 ignored; 0 measured; 91 filtered out; finished in 103.45s
```

## DragonOS：更新工具链并测出 ext4 UB

* 更新工具链到 `nightly-2026-07-21`：
  * https://github.com/KMiri-rs/DragonOS/pull/1
* 测出 ext4 测试 UB（issue）：
  * https://github.com/KMiri-rs/KMiri/issues/273 （`unaligned reference`）
  * https://github.com/KMiri-rs/KMiri/issues/274 （`direct_append_rejects_unwritten_tail` 违反 stack borrow）

  * 失败原因分三类：对齐 UB（9 个）、Stacked Borrows UB（11 个）、地址空间耗尽（30 个）
  * 完整清单见：https://github.com/orgs/KMiri-rs/discussions/272
