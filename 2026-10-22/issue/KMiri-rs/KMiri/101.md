# Unused shim: `miri_terminate_current_thread`

- **Comments**: 0
- **Labels**: KMiri-API

## Body

We can't simply expose a `miri_terminate_current_thread` shim to turn a thread state to `Terminated`.

We should run MIR steps to normally finish the task and `kernel_task_entry` to have kmiri clean  up the stack.

It basically means that calls in `kernel_task_entry` should always return, otherwise https://github.com/KMiri-rs/KMiri/issues/97 will be hit.

So  `miri_terminate_current_thread` becomes useless, and should be removed.
