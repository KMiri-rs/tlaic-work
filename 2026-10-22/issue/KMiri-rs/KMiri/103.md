## Body

For the following code, the implicit `drop(task)` emits vague `core::ptr::drop_in_place` while the instance name in backtrace is fully qualified as shown in https://github.com/KMiri-rs/KMiri/issues/102

```rust
#[ostd::ktest::miri_main]
fn kernel_main() {
    println!("Hello world from guest kernel!");
    let task =
        ostd::task::TaskOptions::new(|| ostd::miri_println!("A custom task from miri_main!"))
            .build()
            .unwrap();
}
```
