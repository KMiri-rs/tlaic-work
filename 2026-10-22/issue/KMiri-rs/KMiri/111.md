## Body

It's useful to know what the real layout looks like in the type.

`repr(C)` almost demostrates the type layout, so everyone can figure out the field order and paddings.

But the layouts of default `repr(Rust)` and codegen structures (closures, async fn etc) are not guaranteed, but it doesn't mean it should be hidden from low-level code writers.

It'd also be useful to know the niches for every type in the code, like https://niche.rs/ does.
