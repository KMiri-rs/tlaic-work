## Body

When I run this command in tockos' kernel crate

```bash
MIRIFLAGS="--debugger --remap-path-prefix=$(rustc --print=sysroot)/lib/rustlib/src/rust/library/= --remap-path-prefix=$(realpath .)/=" \
  cargo miri test -- test_enqueue_dequeue
```

the debugger fails to display the test thread. (maybe I just didn't stop at a right entrypoint, because debugger succeeded to jump to another task in Asterinas)

I'm also considering a broader case for multi-threaded programs:
* memory space with thread labeled
* states shared across threads
* some interior info from miri's concurrent detector
