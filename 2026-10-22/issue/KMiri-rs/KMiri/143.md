## Body

Although tock's board project specifies the bin target

```toml
[[bin]]
name = "qemu_rv64_virt"
path = "src/main.rs"
```

the `main` fn is defined as 

```rust
/// Main function called after RAM initialized.
#[no_mangle]
pub unsafe fn main() { ... }
```

Miri complains that entry fn is not found:
```rust
tock/boards/qemu_rv64_virt $ cargo miri run --target riscv64imac-unknown-none-elf
error: Miri can only run programs that have a main function.
       Alternatively, you can export a `miri_start` function:
       
       #[cfg(miri)]
       #[unsafe(no_mangle)]
       fn miri_start(argc: isize, argv: *const *const u8) -> isize {
           // Call the actual start function that your project implements, based on your target's conventions.
       }

error: aborting due to 1 previous error; 1 warning emitted
```
