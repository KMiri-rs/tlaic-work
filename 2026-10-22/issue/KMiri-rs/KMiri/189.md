## Body

```rust
/blueos-dev/kmiri $ cargo b
error[E0463]: can't find crate for `tracing_attributes` which `rustc_middle` depends on
 --> /blueos-dev/kmiri-helper/src/lib.rs:3:1
  |
3 | extern crate rustc_middle;
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^ can't find crate
```

Some dynamic libraries are not in sysroot:

```
$ fd middle /tmp/sysroot
$ fd tracing_attributes /tmp/sysroot
```

We must bundle rustc's dist libraries with stage 1 or 2 artifacts. These dyn libs seem not distributed by simple `./x.py install --stage 2`, so need to manually copy them, like
`cp -r build/tmp/tarball/rustc-dev/x86_64-unknown-linux-gnu/image/lib/rustlib $${DESTDIR}/usr/local/lib/`.
