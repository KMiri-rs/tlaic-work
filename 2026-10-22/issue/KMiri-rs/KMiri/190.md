## Body

```bash
kmiri $ make test
cd /KMiri/vivo-blueos/kmiri && ./miri install --debug && \
cd /KMiri/vivo-blueos/kmiri-helper && cargo install --path .
Error: command not found: `rustup`
make: *** [Makefile:6: install] Error 1
```

BlueOS has customed Rust toolchain and build process that doesn't rely on `rustup`.

The only reason to rely on `rustup` seems to ensure the toolchain environment is complete to compile the code or switch toolchain with ease.

So we need to adjust `miri-script` to not rely on `rustup` if absent.
