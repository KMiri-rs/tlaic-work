## Body

String interpolation in `cmd!` has some quirks.

For example, if `toolchain` has leading whitespace, `{cargo_bin}{toolchain}` won't split and instead is considered to be a whole command.


```
cmd!(self.sh, "{cargo_bin}{toolchain} install {locked_flag...} {cargo_extra_flags...} --path {path} --force --root {sysroot} {features...} {args...}").run()?;
```
```
kmiri $ make test
cd /home/zjp/KMiri/kmiri && ./miri install --debug && \
cd /home/zjp/KMiri/kmiri-helper && cargo install --path .
info: This is the version for the rustup toolchain manager, not the rustc compiler.
info: the currently active `rustc` version is `rustc 1.99.0-nightly (87e5904f5 2026-07-20)`
$ cargo +nightly-2026-07-21-x86_64-unknown-linux-gnu install --locked -Zroot-dir=/home/zjp/KMiri/kmiri --path /home/zjp/KMiri/kmiri/. --force --root /home/zjp/.rustup/toolchains/nightly-2026-07-21-x86_64-unknown-linux-gnu --debug
Error: command not found: `cargo +nightly-2026-07-21-x86_64-unknown-linux-gnu`
make: *** [Makefile:8: install] Error 1
```

The macro is pretty fragile: `cmd!(self.sh, "{cargo_bin} {toolchain} ...")` if `toolchain` has leading whitespace, `cmd!`  won't handle it properly:

```diff
-cmd!(self.sh, "{cargo_bin}{toolchain} install {locked_flag...} {cargo_extra_flags...} --path {path} --force --root {sysroot} {features...} {args...}").run()?;
+cmd!(self.sh, "{cargo_bin} {toolchain} install {locked_flag...} {cargo_extra_flags...} --path {path} --force --root {sysroot} {features...} {args...}").run()?;
```
