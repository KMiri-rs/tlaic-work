# BlueOS: Enable page table in `boot.toml` and test page table code in `miri_start`

- **URL**: https://github.com/KMiri-rs/KMiri/issues/255
- **State**: open
- **Author**: zjp-CN
- **Created**: 2026-10-12T01:57:12Z
- **Updated**: 2026-10-12T02:15:55Z
- **Comments**: 0
- **Labels**: KMiri-API, VivoBlueOS

## Body

Set `page_table` to true in [`boot.toml`](https://github.com/KMiri-rs/vivoblueos-build/blob/7becfc43df7e8ea2abaa54bfba74b74ae559f553/scripts/miri/boot.toml#L1).

And see if [`miri_start`](https://github.com/KMiri-rs/vivoblueos-kernel/blob/6838c67523604547810854912bd757516a79b4ec/kernel/src/miri_boot.rs#L89) has  page table code. If not, initialize page table and do allocations. 
I think we didn't handle page table yet: there are no shims like `kern_miri_set_root_page_table` in the kernel.
