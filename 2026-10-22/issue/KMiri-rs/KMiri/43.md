## Body

The debugger prints new lines incorrectly, because extra newline is inserted:

```rust
ostd::miri_println!("argc={argc} argv={argv:p}\nargs={args:?}");
```

```
┌Output
│argc=
│1
│ argv=
│0x
│10018
│
│args=
│[
```


The desired output is
```
┌Output─────────────
│argc=1 argv=0x10018
│args=[0x1000c]
```
