## Body

miri.py will stop with NoneType errors, because the script doesn't handle the fresh build yet.
```py
Traceback (most recent call last):
  File "miri.py", line 83, in <lambda>
    gdb.post_event(lambda: self.exit_to_another_inferior())
                           ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~^^
  File "miri.py", line 92, in exit_to_another_inferior
    elif (val := self.miri_inferior()):
                 ~~~~~~~~~~~~~~~~~~^^
  File "miri.py", line 146, in miri_inferior
    if status.cmdline.is_cargo_miri():
       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
AttributeError: 'NoneType' object has no attribute 'is_cargo_miri'
```

To run miri.py, run `OSDK_LOCAL_DEV=1 cargo osdk miri test` first to fully build the code with miri, and then run `OSDK_LOCAL_DEV=1 rust-gdb -x miri.gdb --args cargo osdk miri test` to reach desired breakpoints in miri source code.
