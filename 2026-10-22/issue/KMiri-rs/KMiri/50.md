## Body

Launch the debugger, and it immediately aborts. The logs say

```
$ cat target/osdk-miri/os-miri-base/miri-debugger.log
Debugger exited with error:
Custom { kind: Other, error: Custom { kind: Other, error: "The cursor position could not be read within a normal duration" } }

$ cat target/osdk-miri/os-miri-base/miri_diagnostics.txt
warning: unstable feature specified for `-Ctarget-feature`: `ermsb`
  |
  = note: this feature is not stably supported; its behavior can change in the future

error: interpretation was interrupted
  --> src/main.rs:15:9
   |
15 |     let args = unsafe { core::slice::from_raw_parts(argv, argc as usize) };
   |         ^^^^ error occurred here

error: aborting due to 1 previous error; 1 warning emitted
```

The reason is  calls like read and poll  are not allowed in different threads as per https://docs.rs/crossterm/latest/crossterm/event/index.html .
