Currently, a local value is presented by [LocalState](https://doc.rust-lang.org/nightly/nightly-rustc/rustc_const_eval/interpret/struct.LocalState.html) which distinguishes the value as an [Operand](https://doc.rust-lang.org/nightly/nightly-rustc/rustc_const_eval/interpret/operand/enum.Operand.html) (Immediate vs Indirect). 

But since the Rust type can be known, we can show the intepreted value based on the type.
