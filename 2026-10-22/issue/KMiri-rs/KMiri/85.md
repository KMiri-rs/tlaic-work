# `kern_miri_set_cpu_local_base` is unused in Asterinas

- **URL**: https://github.com/KMiri-rs/KMiri/issues/85
- **State**: open
- **Author**: zjp-CN
- **Created**: 2026-06-30T13:49:11Z
- **Updated**: 2026-06-30T13:49:11Z
- **Comments**: 0
- **Labels**: KMiri-API

## Body

`kern_miri_set_cpu_local_base` is a shim for cpu local's `set_base` in Asterinas, but `set_base` is replaced by pure assembly code https://github.com/asterinas/asterinas/pull/1786/changes/c6e6ee9b7a8fc945b3619b632930d3403a2afb63


The shim is still necessary because different OS has different strategy of cpu local base address.
