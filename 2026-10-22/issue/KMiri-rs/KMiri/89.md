## Body

`addr_from_alloc_id` takes AllocId and returns vaddr, allocating vaddr when the allocation doesn't have such vaddr.

It also records the paddr in int_to_ptr_map. The paddr is found via `mirch::page_walk_or`  or `kernel_code_vaddr_to_paddr`.

We should refactor all physical addresses saved in state by making them virtual addresses, because each vaddr must correspond to a paddr through page table, whereas a paddr can be shared in multiple vaddr. `alloc_id_from_addr` also needs the fix because it currently takes paddr, while  vaddr should be taken.

Paddr is linear mapped to vaddr  in kernel code, but not in free pages due to virtual mapping.
