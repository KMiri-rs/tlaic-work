## Body

With https://github.com/KMiri-rs/KMiri/issues/90 fixed, now we have the ub report

```rust
Terminate ThreadId(1). Live thread count: 1 (Thread: ["main"])
error: Undefined Behavior: constructing invalid value of type !: encountered a value of the never type `!`
   --> /home/zjp/KMiri/asterinas/ostd/src/boot/mod.rs:142:14
    |
142 |     unsafe { __ostd_main() };
    |              ^^^^^^^^^^^^^ Undefined Behavior occurred here
    |
    = help: this indicates a bug in the program: it performed an invalid operation, and caused Undefined Behavior
    = help: see https://doc.rust-lang.org/nightly/reference/behavior-considered-undefined.html for further information
    = note: this is on thread `main`
    = note: stack backtrace:
            0: ostd::boot::start_kernel
                at /home/zjp/KMiri/asterinas/ostd/src/boot/mod.rs:142:14: 142:27
            1: ostd::arch::boot::miri_boot
                at /home/zjp/KMiri/asterinas/ostd/src/arch/miri/boot/mod.rs:73:14: 73:28
            2: miri_start
                at src/main.rs:18:5: 18:34
```

`__ostd_main` is [defined](https://github.com/KMiri-rs/asterinas/blob/2bf3f4386a688082042f5247103fad0e3539feda/ostd/src/boot/mod.rs#L133-L142) as an external function returning the never type.

For miri's `__ostd_main` [implementaion](https://github.com/KMiri-rs/asterinas/blob/2bf3f4386a688082042f5247103fad0e3539feda/ostd/libs/ostd-macros/src/lib.rs#L142-L163), the main thread continues due to no task, and the function successfully returns.

A fix is to call `miri_terminate_current_thread` on the main thread, and tell kmiri the program exits successfully.
