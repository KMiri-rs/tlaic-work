## Body

Steps to reproduce errors:
1. `make nixos`
2. `make run_nixos`

Asterinas NixOS will successfully run, but I get "database disk image is malformed"  error when installing CLIs:
```
[root@asterinas:~]# nix profile install --extra-experimental-features "nix-command flakes" nixpkgs#OVMF
error: executing SQLite statement 'pragma synchronous = normal': database disk image is malformed, database disk image is malformed (in '/nix/var/nix/db/db.sqlite')

[root@asterinas:~]# nix-shell -p tree
error: executing SQLite statement 'pragma synchronous = normal': database disk image is malformed, database disk image is malformed (in '/nix/var/nix/db/db.sqlite')

[root@asterinas:~]# nix-shell -p fish
error: executing SQLite statement 'pragma synchronous = normal': database disk image is malformed, database disk image is malformed (in '/nix/var/nix/db/db.sqlite')
```

Or even abort the OS like this:

