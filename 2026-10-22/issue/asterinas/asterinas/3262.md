# Build docker images more actively in CI

## Body

### Motivation

CI currently only [builds Docker images](https://github.com/asterinas/asterinas/actions/workflows/publish_docker_images.yml) when pushing to the main branch with `DOCKER_IMAGE_VERSION` changed, or when triggered manually, as per the [workflow file](https://github.com/asterinas/asterinas/blob/b166a03c79ac0b7962efad25043ff5921563e6e7/.github/workflows/publish_docker_images.yml#L3-L12).

As a result, there is no way to know whether image building has been broken until someone bumps the Docker version, blocking development even when only a new tool needs to be installed.

### Proposal

Run the image build as a regular job, triggered on every push. This helps detect build issues early and fix them in a timely manner.
