## Body

close https://github.com/KMiri-rs/KMiri/issues/75


This PR skips `invoke_ffi_init_funcs()` when running under `#[cfg(kmiri)]`.

That function relies on linker-defined symbols (`__sinit_array` / `__einit_array`) and assembly/link-time behavior, which KMiri does not model yet ( see https://github.com/KMiri-rs/KMiri/issues/78 if we want to model it ). Running it under KMiri causes invalid failures unrelated to normal kernel logic.
