## Summary
- add UML built-in sample `SAMPLE_KMIRI_PASSTHROUGH` with `/proc/kmiri_pt` command interface
- add `initramfs-kmiri.sh` and `miri-unit-passthrough` target for black-box passthrough experiment
- route bitmap tests through bindings path under `--cfg KMIRI_BITMAP_PASSTHROUGH`


<details><summary>Details</summary>
<p>

- 新增了 UML 侧的 kmiri helper：`samples/rust/kmiri_passthrough.c`。  
  它通过 `/proc/kmiri_pt` 提供黑盒调用入口，支持 bitmap 相关的一批内核接口转发（如分配/释放、查找位、置位清位、copy_and_extend）。
- 增加了样例配置与构建接入：`samples/rust/Kconfig`、`samples/rust/Makefile`。  
  即新增 `SAMPLE_KMIRI_PASSTHROUGH` 开关，并把 helper 目标编进 samples/rust 构建系统。
- 新增最小化 initramfs 启动脚本：`initramfs-kmiri.sh`。  
  启动后挂载 hostfs，轮询 host 侧请求文件，把请求透传到 `/proc/kmiri_pt`，再把结果写回响应文件。
- 在 `makefile.local` 增加了 `miri-unit-passthrough` 目标。  
  这个目标会自动：配置并构建 UML、启动最小内核进程、等待桥接就绪、设置 passthrough 环境变量、再触发 bitmap 的 miri 单测。并且做了配置隔离，避免触发交互式 Kconfig。
- 修改 `rust/kernel/bitmap.rs` 的条件编译逻辑。  
  在 passthrough 场景下走原 binding 路径，而不是原先 `cfg(miri)` 的纯 Rust 模拟路径。


</p>
</details>
