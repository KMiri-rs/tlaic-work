## Summary
- add `KMIRI_BITMAP_C2RUST` miri path in `rust/kernel/bitmap.rs`
- add c2rust-transpiled bitmap runtime implementation in `rust/kernel/bitmap_c2rust.rs`
- add `make -f makefile.local miri-unit-c2rust` one-command target
