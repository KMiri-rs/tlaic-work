## Body

This PR supersedes https://github.com/KMiri-rs/miri/pull/16 , https://github.com/KMiri-rs/miri/pull/15 , and https://github.com/KMiri-rs/miri/pull/6 .

A real fix for https://github.com/KMiri-rs/KMiri/issues/19 , https://github.com/KMiri-rs/KMiri/issues/49 , https://github.com/KMiri-rs/KMiri/issues/61 , and https://github.com/KMiri-rs/KMiri/issues/60 .

Given the only possible stack allocation is for return value, we reserve the space before all locals are allocated, resume the stack address for return value in before_stack_pop, and check the address is correct in after_stack_pop.

The maximum stack footprint is still 6MB,  the same as in https://github.com/KMiri-rs/miri/pull/16.
