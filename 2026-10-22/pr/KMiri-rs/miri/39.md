## Body

Hot fix https://github.com/KMiri-rs/KMiri/issues/148 , but not dig into the real problem.

Before the fix, the sysroot defaults to `~/.cache/miri` where miri does something 

```
Preparing a sysroot for Miri (target: riscv64imac-unknown-none-elf) 
at "/home/zjp/.cache/miri"... fatal error: failed to build sysroot: sysroot build failed;
```

The fix is replace the  sysroot point for tockos by rustc's default sysroot.

```
# rustc --print sysroot
MIRI_SYSROOT=/home/zjp/.rustup/toolchains/nightly-2026-07-21-x86_64-unknown-linux-gnu
```

NOTE: the issue does not happen in asterinas tests, and it suddenly appears in the kmiri project.
