## Summary
- add `kmiri_passthrough` shim module for bitmap-related kernel symbols
- support passthrough request/response transport via `KMIRI_PASSTHROUGH_DIR` and optional proc endpoint
- integrate shim dispatch into foreign item fallback path

<details><summary>Details</summary>
<p>

- 新增 `src/shims/kmiri_passthrough.rs`。  
  实现 bitmap 相关 symbol 的 passthrough shim：从 Miri 解释态取参数、编码请求、发送到内核 helper、解析返回并写回解释器内存/返回值。
- 修改 `src/shims/foreign_items.rs`。  
  在 foreign item fallback 链路里接入 `kmiri_passthrough`，命中支持符号时直接由 passthrough 处理。
- 修改 `src/shims/mod.rs`。  
  注册新 shim 模块。
- 传输层同时支持两种端点环境变量：  
  `KMIRI_PASSTHROUGH_DIR`（目录 req/resp 方式）和 `KMIRI_PASSTHROUGH_PROC`（直接 proc 方式）；当前实验主路径是目录方式，并做了请求 ID 机制以降低竞态风险。

</p>
</details> 

## Validation
- `cargo build -q --bin miri`
- `make -f makefile.local miri-unit-passthrough` (from linux repo)
