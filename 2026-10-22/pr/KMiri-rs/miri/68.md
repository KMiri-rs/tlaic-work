## Body

## Summary
- extend kmiri libc shims to accept common alias symbols:
  - `__libc_malloc` / `__libc_calloc` / `__libc_free`
  - `__GI_memcpy` / `__builtin_memcpy`
  - `__GI_memset` / `__builtin_memset`
- keeps c2rust-generated bitmap runtime stable across libc symbol variants

## Validation
- `cargo build --bin miri`
- used by linux side target: `make -f makefile.local miri-unit-c2rust`
