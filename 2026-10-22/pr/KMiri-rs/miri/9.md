## Body

This PR updates the debugger TUI output handling so stdout/stderr text is rendered with correct line boundaries.

In practical terms, it does two things:
- In [`src/debugger/state.rs`](/home/zjp/KMiri/kmiri/src/debugger/state.rs), it renames the captured output record from `OutputLine` to `OutputSpan`.
- In [`src/debugger/tui/pane/output.rs`](/home/zjp/KMiri/kmiri/src/debugger/tui/pane/output.rs), it changes the output pane renderer to treat each captured output chunk as a span that may continue the previous visible line, instead of blindly splitting every chunk on `\n`.

The effect is that multi-line output and text without a trailing newline are displayed more faithfully in the debugger’s output pane.

fix https://github.com/KMiri-rs/KMiri/issues/43
