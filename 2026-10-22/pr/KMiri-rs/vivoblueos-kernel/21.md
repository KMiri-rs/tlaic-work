Two allocators are supported

```bash
# use allocator implemented in blueos to interprete host libtest and run kernel unit tests
$ make miri_test_kernel USE_BLUEOS_ALLOC=true
```

```bash
# use libstd's allocator to interprete host libtest and run kernel unit tests
$ make miri_test_kernel
```
