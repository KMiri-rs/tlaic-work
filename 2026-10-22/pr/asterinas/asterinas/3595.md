## Body

[`cargo-udeps`](https://github.com/est31/cargo-udeps) identifies unused dependencies within each crate, helping to mitigate supply chain risks.

The tool successfully detected unused dependencies in [this discussion](https://github.com/asterinas/asterinas/pull/3591#discussion_r3587677609). It generates the report below, helping clean up these dependencies on a per-target basis (see [this commit](https://github.com/asterinas/asterinas/commit/7ff4f02fd570465b288c59649d96c1b2edb56f33)).


```
unused dependencies:
`aster-framebuffer v0.1.0 (/asterinas/kernel/comps/framebuffer)`
└─── dependencies
     ├─── "aster-console"
     └─── "aster-input"
`aster-kernel v0.1.0 (/asterinas/kernel)`
└─── dependencies
     └─── "aster-mlsdisk"
`aster-virtio v0.1.0 (/asterinas/kernel/comps/virtio)`
└─── dependencies
     └─── "aster-systree"

`aster-rights v0.1.0 (/asterinas/kernel/libs/aster-rights)`
└─── dependencies
     └─── "aster-rights-proc"
`typeflags v0.1.0 (/asterinas/kernel/libs/typeflags)`
└─── dependencies
     └─── "typeflags-util"

`aster-i8042 v0.1.0 (/asterinas/kernel/comps/i8042)`
└─── dependencies
     ├─── "aster-cmdline"
     ├─── "aster-input"
     ├─── "bitflags"
     ├─── "component"
     ├─── "ostd"
     └─── "spin"

Note: These dependencies might be used by other targets.
      To find dependencies that are not used by any target, enable `--all-targets`.
Note: They might be false-positive.
      For example, `cargo-udeps` cannot detect usage of crates that are only used in doc-tests.
      To ignore some dependencies, write `package.metadata.cargo-udeps.ignore` in Cargo.toml.
```

I've opened https://github.com/asterinas/asterinas/pull/3608 to integrate udeps check.
